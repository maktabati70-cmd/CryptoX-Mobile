# CRYPTO X — تطبيق جوال مستقل (أندرويد)

تطبيق مستقل بالكامل: لا يحتاج حاسوباً ولا خادماً. كل التحليلات والبوت تعمل على الجوال نفسه وتتصل مباشرة بالمنصات.

## ما يعمل داخل الجوال
- أسعار حية مع مصادر احتياطية تلقائية (Bybit ثم OKX) وحارس لحدود الطلبات يمنع الحظر.
- محرك المؤشرات الـ25 كاملاً + كشف الخمول + التعلم الآلي + الحالات المشابهة + أنماط الشموع + الأهداف.
- التوقعات: عملات مرشحة للصعود والهبوط مع الأسباب.
- بوت التداول الفوري على Binance أو Bybit: تجريبي (افتراضي) أو حقيقي، شراء ذكي، هدف ربح صافٍ بعد الرسوم، أمر بيع محدد يوضع على المنصة فوراً.
- الأخبار مترجمة للعربية، المعادن والأسواق، الصفقات الناجحة، التنبيهات بإشعارات أندرويد، والذكاء الاصطناعي (اختياري).

## الأمان
- مفاتيح المنصات تُحفظ مشفّرة داخل الجوال (Android Keystore)، ولا تُرسل إلا للمنصة نفسها.
- أنشئ المفتاح بصلاحية التداول الفوري فقط، ولا تفعّل السحب أبداً.

## العمل في الخلفية
البيع عند الهدف مضمون حتى مع إغلاق التطبيق لأنه أمر محدد على المنصة.
الشراء التلقائي ووقف الخسارة والتنبيهات تعمل ما دام التطبيق مفتوحاً.

تطوير أبو عبدالله الشامي — التحليلات آلية وليست نصيحة استثمارية.
